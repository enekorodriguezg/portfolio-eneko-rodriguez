Proyectos

Una selección de proyectos de backend, datos e infraestructura: desde una API de pedidos B2B desplegada con Docker hasta análisis de lenguaje natural y servidores que se configuran con un solo script.

  1. 01

    NexSale-B2B

    Backend transaccional para la gestión de pedidos y ventas entre empresas. API REST con autenticación JWT y control de acceso por roles (administración, comerciales y almacén), generación de facturas en PDF y RTF, y despliegue completo con Docker Compose: base de datos MySQL y Apache como proxy inverso delante de FastAPI. Proyecto en desarrollo.

    Tecnologías
    Python, FastAPI, SQLAlchemy, Pydantic, MySQL, JWT, Docker Compose, Apache

    Repositorio ↗

  2. 02

    Analítica NLP: WhatsApp frente a Telegram

    Pipeline de procesamiento de lenguaje natural y Machine Learning que analiza reseñas de usuarios para entender por qué se quedan o se van de cada aplicación. Incluye limpieza y lematización del texto, modelado de temas con LDA, comparativa entre clasificadores clásicos y un LLM (Gemma 2) con few-shot prompting, y dashboards en Tableau. Proyecto en equipo de cuatro personas.

    Tecnologías
    Python, Scikit-learn, Pandas, NLTK, TF-IDF, LDA, SMOTE, LangChain, Ollama, Tableau

    Repositorio ↗

  3. 03

    Aplicación web full stack: Pokédex API

    Plataforma en Flask que consume APIs REST externas y las presenta en una interfaz dinámica con Jinja2. La arquitectura se organiza en Blueprints para que sea escalable y mantenga separadas las rutas y la lógica de negocio.

    Tecnologías
    Python, Flask, Jinja2, Blueprints, APIs REST
    Acceso a la demo
    usuario admin · contraseña adminrol de administrador: puedes aprobar cuentas nuevas. Los datos se restauran en cada reinicio.

  4. 04

    Automatización de sistemas y servidores (IaC)

    Herramientas de Infrastructure as Code en Bash que automatizan el despliegue de servidores web y la configuración de Nginx. Incluyen la gestión automatizada de bases de datos y la orquestación de los servicios del sistema con Systemd.

    Tecnologías
    Bash, Linux, Nginx, Systemd
